# sysadmin_repo
# Это учебный репозиторий
# Практика по Terraform и Ansible для Яндекс Облака. Инфраструктура как код.
# Облачная версия
## Структура репозитория

Проект разделён на две логические части: описание инфраструктуры и её автоматизация.

sysadmin_repo/
├── Terraform/ # Описание инфраструктуры в Yandex Cloud
│ ├── main.tf — ресурсы: VPC, подсеть, ВМ (proxy, backend1, backend2), SG
│ ├── variables.tf — объявление переменных
│ ├── outputs.tf — вывод публичных IP-адресов
│ └── terraform.tfvars — значения переменных
│
└── Ansible/ # Автоматизация настройки ОС и сервисов
├── ansible.cfg — конфигурация Ansible
├── inventory.ini — список хостов с текущими IP
├── playbook.yml — главный плейбук (запускает роли)
└── roles/ — модульные роли
├── backend/ — установка nginx, страница бэкенда
└── proxy/ — настройка балансировщика на порту 3000


> ⚠️ **Важно:** Файлы `sa-key.json`, `terraform.tfstate` и их бэкапы исключены из репозитория через `.gitignore`. Они хранятся локально и не должны попадать в публичный доступ.
